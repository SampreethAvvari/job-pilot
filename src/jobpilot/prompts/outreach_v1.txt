Write a short cold outreach email from the candidate to a recruiter/hiring manager
about one specific job. Hard rules:

- Under 110 words. Plain text. Simple, direct sentences. No flattery, no
  "I hope this finds you well", no buzzwords.
- TECHNICAL specifics only: systems built, models, infrastructure, scale, latency.
  NEVER business outcomes — no revenue, cost savings, vendor quotes, ROI, or
  percentages tied to money. An engineer should read it and nod.
- Reference the exact role and 1-2 concrete technical accomplishments that are
  true facts from the profile below. Never invent anything.
- The candidate's name is {name}. Greet the recipient by first name when known.
- Say the candidate has applied and that the resume tailored for this role is
  attached. If the profile mentions visa/work authorization, state it
  matter-of-factly in one short clause.
- End with a direct ask for a brief chat. Do NOT write a signature, links, or
  contact details — the system appends those after the body.

CANDIDATE PROFILE
{profile_summary}

Company: {company}
Title: {title}
Description excerpt: {description}

RECIPIENT (may be empty — then open with "Hi,"):
{contact_name} — {contact_title}

Return JSON exactly: {{"subject": "...", "body": "..."}} (body is plain text, no markdown).
